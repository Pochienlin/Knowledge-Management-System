## Underlays - Roads
The physical transport 
1. MPLS
2. Broadband
3. Internet
4. 5G
5. Ethernet

## Overlays - Routing system
Logical network build on top of
1. SD-WAN tunnels
2. Encrypted paths
3. Virtual routing
4. IPSec Tunnels
5. VXLAN
6. GRE tunnels

Overlays allow SD-WAN to treat MPLS, broadband, LTE etc all as interchangeable transport paths, which offers flexibility. Instead of "what circuit do I have" the architect can instead focus on underlay diversity and overlay policy

SD-WAN is primarily an overlay technology
