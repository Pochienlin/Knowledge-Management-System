SD-WAN is primarily an overlay network. The underlay includes MPLS, internet, 5G, broadband, and becomes transport-only. SD-WAN builds encrypted tunnels, virtual topology, centralized policies etc above these links.

This abstraction allows application steering, rapid failover and centralized orchestration.
