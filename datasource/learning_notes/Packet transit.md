## Dedicated Internet Access - DIA
Enterprise-grade internet access with:
1. Dedicated bandwidth
2. SLA backed internet
3. Business grade support
4. (Usually) symmetric speeds

Used mostly by:
1. Enterprise branches
2. HQs
3. SD-WAN underlays
4. Cloud access

---
## IP Transit
internet backbone connectivity for network / providers. Typically bought by ISPs, carriers, cloud providers and international exchange (IX) participants. Transit providers give:
1. Global internet routing access
2. Full BGP tables
3. upstream internet reachability

Large carriers buy / sell transit to each other

---
## MPLS VPN
Private routed enterprise WAN connectivity. Traffic does NOT traverse to public internet routing table
Advantages include:
1. QoS
2. Predictability
3. routing isolation
4. SLA guarantees
