Historically, enterprises use MPLS VPNs from carriers because
- Predictable latency
- QoS guarantees
- Private routing
- SLA-backed performance

Carrier MPLS networks acted like private enterprise backbones. 

## Pros & Cons - MPLS VPNs

| Advantages              | Disadvantages            |
| ----------------------- | ------------------------ |
| Reliable                | Expensive                |
| Traffic prioritization  | slow provisioning        |
| Deterministic behaviour | poor cloud perfomance    |
|                         | centralized architecture |
This makes MPLS VPN problematic in the cloud era
