Last mile addresses delivery concerns - can we install reliably? 
Global backbone addresses reachability concerns - can we carry traffic globally?

Telcos with strong backbones may still depend on local providers for local loop in last mile designs.
## Last mile
Connection from customer site to the nearest provider POP

Examples:
- Fibre access
- Broadband
- Local loop
- Metro-E

These are often country-specific, outsourced to local ISPs and operationally messy. Most deployment delays occur here

---
## Global backbone
Carrier's international core network

Includes:
- Submarine cables
- Global PoPs
- International MPLS core
- Peering / transit infrastructure

Determines global reach, latency optimization, resilience, intercontinental performance. Ideally the telco should have a good backbone and also good local delivery.
