## Private Cloud connectivity
Enterprises initially depended on normal internet access to reach cloud. Problems started emerging as a result, such as:
1. Unpredictable latency
2. Internet congestion
3. Inconsistent performance
4. Security / compliance concerns
5. Lack of [[Service level agreement for networks | SLA]]

In response, critical applications started moving into the cloud. So enterprise demanded predictable private cloud access. This led to [[Public cloud interconnects | cloud on-ramp]] options such as AWS Direct Connect, Azure ExpressRoute, Google Cloud Interconnect.
