A Wide Ares Network (WAN) connects geographically separated enterprise locations:
- Branch offices 
- Factories
- Retail stores
- Cloud environments
- Remote workers
- Data centres

The WAN exists so applications and users can communicate reliably and securely across distance

| Historically                                                                                                        | Modern enterprise networks                                       |
| ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| - Apps lived in central DCs<br>- Traffic flowed branch to HQ / DC<br>- Networks were designed around centralization | - SaaS (MS365, Salesforce)<br>- Public cloud<br>- Remote workers |
| Branch --> HQ                                                                                                       | Branch / User --> Internet / Cloud                               |
