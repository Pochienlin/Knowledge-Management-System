Traditional WAN failover was often active-passive, e.g. MPLS active, internet backup idle. This results in wasted bandwidth and slower failover. [[SD-WAN]] instead uses acive-active architecture so that multiple links carry traffic simultaneously. 

This results in 
- better bandwidth utilization
- dynamic steering
- improved resilience 
- faster failover
